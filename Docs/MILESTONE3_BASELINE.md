## Lessons from Graphical Pass 2 (avoid repeating)

| Problem | Rule |
|---|---|
| Single-object FBX lost its `__Suffix` (Unity collapses it onto a root named after the file) | `HeroKit.Instantiate` reads the suffix from the mesh name. Keep the `<Asset>__<Material>` naming in Blender. |
| The green "waved like water" | `HeroKit.Surface()` defaults to **wind 0**. Only meshes with baked wind weights in vertex alpha may sway; course surfaces are protected by `TropicalScene_CourseSurfacesDoNotSway`. |
| Old plants rendered stripes | Generated mesh assets must not share file names with `TropicalKit` meshes in `Kit/Meshes`; use the `Hero_` / `HeroLod_` prefixes for new ones. |
| `FrameCostProbe` crashed | URP throws if MSAA changes while XR runs; MSAA stages are desktop-only. Don't change MSAA at runtime in XR. |
| PlayMode tests | They start OpenXR, so Local Claude runs them only with SteamVR closed. Budget a local round trip for each test batch. |
| Half-rate pacing | Caused by SteamVR/stream state, not geometry (the probe showed hiding all scenery changed nothing). Don't cut near-field detail for it; measure with the session log's "pacing at N Hz" line. |
| Scene size | Round 2 is 2.06M triangles at LOD0 and still holds 90 Hz. Keep LODs, culling and selective shadow casting for the new islands. |

## Update: cluster music is already implemented (Local Claude, `8ac0042`)
All five Tropical tracks are in. Do **not** build a second music system; extend this one.

**What exists:**
- `WorldTheme.musicClusters`: an array of `MusicCluster { name, firstHole, lastHole, clip }`, with `MusicCluster.For(clusters, hole)`.
- Tropical clusters are set in `SceneBuilder.BuildTropicalScene` (Starting 1–2, Jungle 3–4, Temple 5–6, Volcanic 7–8, Summit 9). To regroup holes, change only those ranges.
- `MusicPlayer` (`Runtime/Feedback`):
  - two 2D sources;
  - follows `CourseController.HoleStarted`;
  - no restart within a cluster;
  - 3 s crossfade into a new cluster;
  - 2.5 s tail-to-start loop crossfade;
  - a missing clip keeps the current music and logs a warning;
  - `Volume` property, default 0.55.
- Tests in `Tests/PlayMode/MusicTests.cs`.
